## ✨ Features & Functionality

* **Dynamic Product Catalog:** Loads product cards asynchronously via the Fetch API using `async/await` from an external JSON data source.
* **Live Search Bar:** Filters products in real-time as you type using modern event listeners.
* **Category Filtering:** Seamless filtering system (All, Electronics, Clothing, Footwear, Books) that works simultaneously alongside live search.
* **Interactive Shopping Cart Drawer:** Fully functional offcanvas cart supporting item additions, quantity modifications (`+` / `-`), deletions, and automated running subtotal updates.
* **LocalStorage Persistence:** Cart state is securely saved across browser refreshes.
* **Live Badge Counter:** Instant header counter updates reflecting total cart items.
* **Fallback Handling:** Displays custom user-friendly messages when no matching products are found.
